## 1. 분석 엔진 프롬프트 가드레일 (Prompt Guidelines)

관상 분석 AI 연동 시 다음 가드레일 규칙을 엄격히 준수하여 오락 목적에 부합하는 중립적이고 긍정적인 해석 결과를 생성합니다.

### 1.1 PRD §4.4 5대 금지 표현 (Strict Rule)

다음 5가지 항목에 해당하는 표현은 프롬프트 상으로 금지하며, 출력 시 필터링 대상이 됩니다.

| 금지 분류 | 금지 표현 예시 (비허용) | 허용되는 대체 톤 (허용) |
|---|---|---|
| **외모 평가·비하** | 잘생김/못생김, 찌그러짐, 흉함, 부정적 외모 서술 | 분위기, 느낀점, 분위기가 부드러운, 차분한 인상 |
| **인종·성별·나이 단정** | "동양인처럼 보인다", "나이가 많아 보인다" | 특정 그룹 단정 없이 인상 자체의 느낌 서술 |
| **건강·수명·불행 예언** | 질병 언급, 수명 언급, 사고·사기·불운 예고 | 현재 인상이 주는 긍정적 기운, 마인드 조언 |
| **서열화 및 수치화** | 관상 점수(90점), 등급(A급), 순위 서술 | 점수나 등급 표현 없이 서술형 문장으로 구성 |
| **과학적 사실 주장** | "과학적으로", "통계적으로", "실제로 그렇다" | "재미로 보는", "~한 분위기가 느껴져요" 서술 |

## 2. 결과 JSON 데이터 스키마 (TypeScript Specification)

AI 분석 엔진의 결과 응답(Structured Outputs)은 이하의 TypeScript 타입 정의와 100% 일치해야 합니다.

```typescript
export type ResultItem = {
  id: string        // 부위 식별자 (e.g. "eyes", "nose", "mouth", "forehead")
  title: string     // 부위 소제목 (e.g. "눈매", "콧대와 인중")
  body: string      // 부위별 관상 해석 본문 (2~3줄, 중립적/긍정적 톤)
}

export type ResultData = {
  headline: string  // 한 줄 총평 (e.g. "오늘의 당신은 '차분한 봄볕' 같은 인상이에요")
  items: ResultItem[] // 부위별 해석 카드 배열 (3~5개)
  closing: string   // 마무리 한 줄 문구
}
```

## 4. 입출력 파이프라인 및 응답 검증 (Validation)

1. **입력 이미지 요구사항**:
   - 허용 MIME 타입: `image/jpeg`, `image/png`, `image/webp` (`CONFIG.allowedTypes`)
   - 용량 상한: 8MB 이하 (`CONFIG.maxFileSizeBytes`)
2. **응답 스키마 검증 (E-06 처리)**:
   - `headline`, `items`, `closing` 필드가 누락되었거나 `items` 배열 길이가 1개 이하인 경우 `E-06 (result)` 에러 상태로 전이
3. **금지 표현 검사 (E-09 처리)**:
   - AI 응답 문구 내 금지 키워드(점수, 질병, 비하 단어 등) 감지 시 해당 결과 파기 및 `E-09` 처리
