## 1) 목표와 성공조건

### 1.1 목표

사진 한 장으로 **오락 목적의 관상 해석 카드**를 즉석에서 제공하고, 사용자가 그 화면을 그대로 캡처해 공유할 수 있게 한다.

### 1.2 범위 경계

| 구분 | 값 |
|---|---|
| 화면 | **1개** (상태 전환 방식, 페이지 이동 없음) |
| 기능 | **1개** — 사진 입력 → 관상 해석 출력 |
| 제외 | 로그인·결제·DB. 그 외 제외 항목 8개는 `00_BRIEF.md` §2 |

### 1.3 성공조건

지표 자체는 `00_BRIEF.md` §1에 정의돼 있다. 이 문서는 **각 지표를 어떻게 판정할지**만 정의한다.

| ID | 대응 지표 | 판정 방법 | 판정 시점 |
|---|---|---|---|
| S-1 | 완주율 | 지인 10명에게 링크만 전달(사용법 설명 없음) → 결과 화면 도달 인원을 직접 관찰·집계 (가정) | 배포 후 |
| S-2 | 응답 시간 | "분석 시작" 입력 시점 ~ 결과 카드 렌더 완료 시점을 실기기에서 3회 측정, 중앙값 15초 이내 (가정) | 배포 후 |
| S-3 | 자발적 공유 | 공유를 요청하지 않은 상태에서 캡처·공유 발생 여부 확인 | 배포 후 |
| S-4 | 금지 표현 0건 | 결과 문구 표본을 §4.3 금지 표현 목록과 대조. **표본 수는 미정 → 부록 A Q-G** | **배포 전** |

### 1.4 목표가 아닌 것

- **해석의 정확도·적중률** — 결과물은 오락물이며, 맞았는지 여부를 성공 지표로 삼지 않는다.
- **재방문·리텐션** — 1회성 소비를 전제로 한다.
- **대규모 트래픽 대응** — 지인 그룹 규모를 전제로 한다.

| **US-06** | 사용자로서, 다른 사진으로 한 번 더 해보고 싶다. | ① 결과·에러 화면에서 1회 조작으로 사진 선택 상태로 돌아간다<br>② 재시작 시 고지·동의를 다시 거치지 않는다 (같은 방문 내) |

## 3) 화면 명세

화면은 1개, 그 안에서 **5개 상태**가 전환된다. `00_BRIEF.md`의 4개 상태에 **E(에러)** 를 추가했다 — 프로젝트 지침 §5 체크항목 2·4가 에러 상태 정의를 요구하기 때문이다.

### 3.1 상태 전이

| 상태 | 진입 조건 | 사용자에게 보여야 할 정보 | 가능한 행동 | 다음 상태 |
|---|---|---|---|---|
| **A. 고지·동의** | 최초 진입 | 서비스 이름·성격, 고지 3종, 동의 수단 | 동의 | A → B |
| **B. 사진 선택** | A에서 동의 완료 | 사진 선택 수단, 선택 후 미리보기, 분석 시작 수단 | 사진 선택 / 사진 변경 / 분석 시작 | B → C |
| **C. 분석 중** | B에서 분석 시작 | 진행 중 표시, 예상 소요에 대한 안내 | (없음 — 대기) | C → D 또는 C → E |
| **D. 결과** | 유효한 결과 수신 | 관상 해석 결과, 오락 목적 고지 재노출, 다시하기 수단 | 캡처(OS 기능) / 다시하기 | D → B |
| **E. 에러** | §4.3의 예외 발생 | 원인 안내 1줄, 다음 행동 | 재시도 또는 사진 다시 선택 | E → B, E → C |

```
A(고지·동의) → B(사진 선택) → C(분석 중) → D(결과)
                   ↑                ↓           ↓
                   └────── E(에러) ←┘           │
                   └────────────────────────────┘
```

### 3.2 상태별 필수 요건

| 상태 | 필수 요건 |
|---|---|
| A | 동의하지 않으면 B로 진행 불가. "동의함"이 기본 선택된 상태여서는 안 된다 |
| B | 선택한 사진은 **사용자 기기 안에서만** 미리보기 처리한다 |
| C | 진행 중 표시는 요청 전송 즉시 나타난다. 무한 대기 방지 장치 필요 (§4.3 E-05) |
| D | 결과 항목 구성은 **Q1 확정 후** `03_ANALYSIS-SPEC.md`를 따른다. 이 문서에서 필드를 지정하지 않는다 |
| E | 어떤 예외든 사용자를 빈 화면이나 멈춘 화면에 두지 않는다 |

> 실제 문구·버튼 라벨·레이아웃은 `02_UI-SPEC.md`에서 확정한다. 이 절은 "무엇을 알려야 하는가"까지만 규정한다.

## 4) 기능 명세

### 4.1 기능 목록

| ID | 기능 | 설명 | 완료 판정 |
|---|---|---|---|
| **F-01** | 사전 고지·동의 | 고지 3종을 표시하고 명시적 동의를 받는다. 동의 전 사진 선택 차단 | 동의 전 사진 선택이 불가능함이 확인됨 |
| **F-02** | 사진 선택·미리보기 | 기기 사진 1장을 선택하고 전송 전 확인·교체 | 선택→교체→선택이 오류 없이 반복됨 |
| **F-03** | 분석 요청 | 선택한 사진을 분석 엔진에 전달하고 구조화된 해석 결과를 받는다. **인증 정보는 사용자 기기에 노출되지 않아야 한다** | 결과 또는 §4.3의 정의된 예외 중 하나로 반드시 귀결됨 |
| **F-04** | 결과 카드 렌더링 | 받은 결과를 카드 형태로 표시. 결과 항목 구성은 `03_ANALYSIS-SPEC.md` | Q1 확정 후 별도 정의 |
| **F-05** | 다시하기 | 결과·에러 상태에서 사진 선택 상태로 복귀 | 1회 조작으로 B 상태 진입 |
| **F-06** | 사진 폐기 | 원본 사진을 어디에도 영구 저장하지 않고 분석 처리 직후 폐기 | 저장 경로가 코드상 존재하지 않음이 확인됨 |

### 4.2 데이터 요건

| 구분 | 요건 |
|---|---|
| 입력 | 이미지 1장. 허용 형식·용량 상한은 **미정 → 부록 A Q-A, Q-B** |
| 출력 | 미리 정해진 **고정 구조**로 전달되어야 한다. 화면은 그 구조만 렌더한다. 구조 정의는 `03_ANALYSIS-SPEC.md` |
| 보관 | 없음. 입력 이미지·출력 결과 모두 저장하지 않는다 |

### 4.3 예외 처리

| ID | 상황 | 감지 시점 | 동작 | 재시도 | 사용자에게 알릴 것 |
|---|---|---|---|---|---|
| **E-01** | 동의하지 않고 진행 시도 | A | 진행 수단을 비활성 상태로 유지 (사전 차단) | — | 동의가 필요하다는 사실 |
| **E-02** | 지원하지 않는 형식·손상된 이미지 | B (전송 전) | B에 머무름. 선택 취소 | 즉시 가능 | 사용 가능한 형식 |
| **E-03** | 용량·해상도 초과 | B (전송 전) | B에 머무름. 선택 취소 | 즉시 가능 | 크기 제한 |
| **E-04** | 얼굴이 검출되지 않음 / 2명 이상 검출 | C | E 상태로 전환 | 다른 사진으로 | 얼굴 1명이 정면으로 나온 사진이 필요하다는 안내 |
| **E-05** | 분석 엔진 응답 없음·지연·서버 오류 | C (타임아웃) | C를 종료하고 E 상태로 전환 | 같은 사진으로 가능 | 일시적 문제라는 사실 |
| **E-06** | 응답이 정해진 구조와 다름 / 필수 항목 누락 | C (수신 직후 검증) | 결과를 표시하지 않고 E 상태로 전환 | 같은 사진으로 가능 | 결과를 만들지 못했다는 사실 |
| **E-07** | 분석 엔진 사용 한도 초과 | C | E 상태로 전환 | 시간 경과 후 | 잠시 후 다시 시도 |
| **E-08** | 분석 중 새로고침·화면 이탈 | C | 진행 중 요청을 유지하지 않고 A 상태로 초기화 | 처음부터 | (별도 안내 없음) |
| **E-09** | 결과에 §4.4 금지 표현 포함 | C (표시 직전) | 해당 결과를 표시하지 않고 E 상태로 전환 | 가능 | 결과를 만들지 못했다는 사실 |

> **E-04 다중 얼굴 정책**(거절 vs 가장 큰 얼굴 1개 선택)과 **E-05 타임아웃 시간**은 미정 → 부록 A Q-C, Q-D.
> **E-09 구현 수준**(프롬프트 제약만 vs 후처리 검사 추가)은 미정 → 부록 A Q-E.

### 4.4 결과 문구 제약 (변경 불가)

| 금지 | 예 |
|---|---|
| 외모 평가·비하 | 잘생김/못생김, 특정 이목구비에 대한 부정적 평가 |
| 인종·성별·나이 단정 | "○○인처럼 보인다", "나이가 많아 보인다" |
| 건강·수명·불행 예언 | 질병 언급, 수명 언급, 사고·불운 예고 |
| 서열화 | 점수, 등급, 순위 |
| 사실 주장 | "과학적으로", "통계적으로", "실제로 그렇다" |

허용 톤: 중립적·긍정적, 오락물임이 드러나는 서술.
